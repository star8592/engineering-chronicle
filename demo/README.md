# 工程纪事可视化 Demo V0.2

从仓库根目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory demo
```

浏览器打开 http://127.0.0.1:8766 。单文件页面，无外部依赖、无数据上传。通过 localhost 或 HTTPS 使用 Web Crypto；直接打开文件时由浏览器决定摘要计算可用性。

## 本地检查

```sh
node demo/check-state.cjs
```

使用 Node 标准库的 Web Crypto 运行状态逻辑测试：两类记录切换、早期节点不展示当前测试结论、未提交修改不能获得发布资格、故障负例、回放和摘要一致性。该检查使用轻量 DOM 替身，不是浏览器端到端测试。

浏览器布局与下载交互尚未完成自动化验收。当前没有新增 GitHub Actions 工作流；检查由本地执行。此页面是观测快照，不是实时采集服务或 Rust verifier 前端。

## V0.4：动态图成为主界面

- 默认提供明确标注的失败→修复示例图；播放/暂停/逐步/拖动历史游标会改变节点和关系。
- 节点点击打开对应事件与日志；新增节点进入动画，倒放移出动画，选择状态和异常状态同步更新。
- 失败节点及其日志保留，不被复测通过覆盖；缺失/篡改/陈旧示例证据使复测与证据包节点转为异常。
- 真正采集的数据目前只有提交与测试观察，因此真实图的虚线仅表达展示顺序，不冒充架构依赖或因果链。真实架构、Git差异到图结构的映射、实时订阅与实验分叉仍未实现。
- 大历史图只投影当前位置附近六条记录，完整记录仍在时间轴可查。图按容器宽度重新布局，支持减少动画的系统设置。

检查：`node demo/check-graph.cjs`、`node demo/check-state.cjs`、`node demo/check-bundle.cjs`。真实浏览器布局和动画验收仍待完成，不能以模型测试代替。

## V0.6：多视角联动回放

新增演化柱条、相邻版本差异、节点状态组成与关系矩阵，与主图、播放和历史位置联动。差异固定对比上一历史位置，与用户跳转顺序无关；首次位置对比空图。同一提交的工作区测试记录不生成虚构的依赖变化。矩阵点击展示精确清单，示例/导入的顺序关系仍明确标注。默认真实视图落在最后一个已提交清单快照。

柱条以记录位置排列，间隔不代表时间；节点状态不是证据可信度或商用评分。`node demo/check-facets.cjs` 检查计数、相邻基准、重复快照、矩阵端点和保留失败；扩展 `check-state.cjs` 检查柱条跳转和矩阵证据联动。五个检查通过仅代表模型/轻量DOM验证，真实浏览器视觉验收仍待完成。
