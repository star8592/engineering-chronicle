# 工程纪事可视化 Demo V0.2

从仓库根目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory demo
```

浏览器打开 http://127.0.0.1:8766 。单文件页面，无外部依赖、无数据上传。通过 localhost 或 HTTPS 使用 Web Crypto；直接打开文件时由浏览器决定摘要计算可用性。

## V0.4：动态图成为主界面

- 默认提供明确标注的失败→修复示例图；播放/暂停/逐步/拖动历史游标会改变节点和关系。
- 节点点击打开对应事件与日志；新增节点进入动画，倒放移出动画，选择状态和异常状态同步更新。
- 失败节点及其日志保留，不被复测通过覆盖；缺失/篡改/陈旧示例证据使复测与证据包节点转为异常。
- 真正采集的数据目前只有提交与测试观察，因此真实图的虚线仅表达展示顺序，不冒充架构依赖或因果链。真实架构、Git差异到图结构的映射、实时订阅与实验分叉仍未实现。
- 大历史图只投影当前位置附近六条记录，完整记录仍在时间轴可查。图按容器宽度重新布局，支持减少动画的系统设置。

检查：`node demo/check-graph.cjs`、`node demo/check-state.cjs`、`node demo/check-bundle.cjs`。真实浏览器布局和动画验收仍待完成，不能以模型测试代替。

## V0.8：宋韵青绿配色

设计参考宋徽宗相关传世绘画中的绢本设色气质，将绢白、天青、石青、石绿、赭金、朱砂作为现代界面色名。它们是设计解释，HEX值不是宋代颜料测量值，也不声称已证明徽宗个人偏好的固定六色配方。底色与大面积留白采用绢色，依赖图用青绿，外部依赖以石青区分，赭色表示变更，朱砂用于失败。文字和主要动作采用较深色以保留可读性。

参考：故宫《赵佶芙蓉锦鸡图轴》https://www.dpm.org.cn/collection/paint/230125.html （馆藏说明标注“传”）；波士顿美术馆《Five-colored parakeet on a blossoming apricot tree》https://collections.mfa.org/objects/29081/fivecolored-parakeet-on-a-blossoming-apricot- （检索元数据，详情页自动访问受限）；辽宁日报《辽宁省博物馆藏〈瑞鹤图〉——千年瑞鹤，一图传世》https://news.lnd.com.cn/system/2026/02/22/030547299.shtml 。此项只调整视觉表现，图与证据语义不变。
