# V0.1 协议实现进度

状态：EC-002 第一小步，尚未冻结完整 wire protocol。

已实现：不透明 ASCII 标识（1–128字节，字母/数字开头）、规范无符号十进制 u64 序号、声明的 SHA-256 小写摘要格式、来源位置与平台位置的分离类型、明确的解析错误。

序号按字符串表示，避免大于2^53的整数经过浮点往返；溢出拒绝，不回绕。解析摘要只校验格式，不核验内容。标识不得直接拼接为文件系统路径。来源 epoch 只是类型字段，登记和授权尚未实现。

未实现：JSON重复键/深度/大小限制、JCS规范字节、DSSE签名、信任政策、来源授权、完整Statement/Receipt/Assessment模型。因此M07/M08均尚未完成。
