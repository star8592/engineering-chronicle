# ADR-0002：开源与商业化路线

日期：2026-10-09（Asia/Shanghai）
状态：用户已确认推进方向；定价与市场需求仍待实验验证。

## 用户决定

用户在中立商业评估后表示：“同意，就按照这个方案来推进”。该授权支持独立工程建设、核心开源与商业试点准备，不代表允许擅自联系客户、收费或声称认证。

## 决策

1. 首款产品为 AI 软件变更的可验证交付记录，围绕精确需求/提交/产物、验证范围、证据包和时间轴。
2. 协议、离线验证器、SDK、基础账本及常用适配器采用 Apache-2.0；允许自托管、导出与独立核验。
3. 基础权限和可靠核验不作为付费限制；商业价值来自托管、组织治理、企业集成、运维支持与 SLA。
4. 不要求替换 Git、CI 或现有观测工具；优先关联和核验其原始结果。
5. 用 DevControl 自用闭环验证技术，再访谈10–15个目标团队，安排3个外部试点。
6. 团队版每组织每月99–299美元仅是报价实验，尚未确定套餐、收款或合同。
7. 至少两家外部团队持续使用且愿意付费，再扩大平台范围。这是决策门槛，尚未达成。
8. 衡量验收/调查时间、重复使用、续费、支持成本和包含存储/索引/查询/模型/部署支持的单位经济。

## 风险与应对

既有产品覆盖追踪、工程上下文、来源证明及供应链图谱。差异化必须经试点证明；防止只做漂亮图形或重复已有工具。工程宇宙、仿真与自动进化在核心交付闭环后展开。

## 当前未发生

没有客户访谈、外部试点、收入、商业合同、合规认证或生产级保证。公开源码不是公开客户数据或工程秘密。
